# T04 - In-process mutation boundary vertical slice

## Objective
Apply color, complete cut and timeline anchor between fixtures through business setters without networking.

## Shared context and dependencies
T01 typed contracts, T03 scheduling, integration and state contracts.

## Scope and preserved contracts
Use scoped LocalDesktop/LocalQuest/Remote context; remote nested setters suppress echo while preserving domain effects. Target invalidation and typed checkpoints; maintain Core dependency direction.

## Out of scope
Networking, UI controls and unrelated activity/collider changes.

## Automated acceptance criteria
A1. Core/Data/Sync Scene and focused tests compile. A2. Two-fixture production-boundary tests prove color O(1), newest cut preview, timeline anchor advance and typed checkpoint apply. A3. Nested remote/automatic callbacks never echo; unrelated activity/collider flags remain unchanged.

## Verification contract
Static gate then focused `Sync.SceneFocused` EditMode MCP tests; poll job, inspect console, reject skipped/zero/stale results and record timing.

## Human acceptance
Review actual setter hook and invalidation mapping.

## Unresolved decisions
Resolved before implementation: the production setters are `SiteState.Color`, the complete `Cut` definition (including inherited `Plane.Normal`), and `BasicTimeline` anchor properties. Stable targets are column/site IDs, cut ID, and column ID respectively.

## Completion report
- **Site color:** `SiteState` restores the previous notification kind in a `finally` block, so each nested setter is classified independently. Scene-level regressions verify nested color changes set only site-rendering invalidation, while a nested blacklist change also invalidates the activity generator; neither changes collider state. `SiteColor_UsesConstantTimeTargetLookupAcrossThirtyThousandSites` covers object-keyed target lookup.
- **Complete cut:** Remote apply calls production `Base3DScene.UpdateCutPlane` while preserving the normal in the received definition. Axial, coronal, and sagittal scene tests verify the full definition and cut/texture invalidation cascade, with geometry, activity, site, and collider invalidation left clear. `CutDefinition_AppliesCompleteStateAndKeepsNewestPreview` still covers newest-preview selection.
- **Timeline anchor:** `BasicTimeline` anchor setters emit neutral post-change events; automatic playback and nested callbacks are suppressed. `TimelineAnchor_AdvancesAtReceiverAndSuppressesNestedRemoteCallbacks`, `PausedTimelineAnchor_DoesNotAdvanceWithElapsedClockEstimate`, and `TimelineAutomaticPlayback_DoesNotCreateMutationProposals` cover receiver advancement, stopped anchors, and cross-family echo suppression. Monotonic ages are accepted only through an injected estimate; without one, remote playback starts from the received index on receipt.
- **Checkpoint:** typed site-color, cut-definition, and timeline-anchor checkpoint records are captured and prevalidated before application; `TypedCheckpoint_ExportsAndAppliesThroughTheSameRemoteHandlers` and `TypedCheckpoint_PrevalidatesAllTargetsBeforeApplyingAnyRecord` cover apply and atomic validation failure.
- **Verification:** assembly dependency gate passed (44 HBP assemblies, 154 direct edges). Focused `Sync.SceneFocused` EditMode execution produced a fresh NUnit result with 28 passed, 0 failed, 0 skipped, and 0.425 s test duration; it includes the five new nested-state and three-orientation cases. Unity MCP jobs `267c1f85b9ed45b0970eb41946774bc7` and `ab764576ba62471ea67a5207b997e27b` incorrectly reported initialization timeouts (45 s and 120 s), even though Unity Test Runner logged start/finish and the newly timestamped `TestResults.xml` contains the passing run. Console had no errors; it reported an XR Management `StopSubsystems without an initialized manager` warning during test-run shutdown.
