# T06 - Online sequencing, transient reconnect and early Quest proposal driver

## Objective
Prove bidirectional canonical authority and failure handling for the three vertical-slice profiles.

## Shared context and dependencies
T03–T05 outputs; replication, lifecycle and wire contracts.

## Scope and preserved contracts
One fake/prepared incarnation, Desktop acceptance/per-key indexes, Quest optimistic proposals and authoritative correction, fake-clock 500 ms grace and bounded retry.

## Out of scope
Broad matrix coverage, real-scene cutover and offline merge.

## Automated acceptance criteria
A1. Scene/Quest assemblies and tests compile. A2. Both directions converge for color, cut and timeline. A3. Lost ACK does not double-apply; within-grace reconnect is silent; expiry preserves view and abandons history; stale/same-key/disjoint-key cases match the plan.

## Verification contract
Static gate then focused `Sync.SceneFocused` MCP EditMode driver tests, with completed job, console and timing evidence; zero/skipped/stale runs fail.

## Human acceptance
Review correction UX and view preservation.

## Unresolved decisions

## Completion report
Map proposal/canonical paths and failure cases to tests.
