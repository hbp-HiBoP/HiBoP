# T14 - Dual activity-projection coordination

## Objective
Coordinate local projection on both peers while safe operations continue.

## Shared context and dependencies

## Scope and preserved contracts
Start/progress/ready/cancel/fail generations; two-peer sensitive busy scope; automatic/manual policy; newest safe pending parameters; stale-result protection and immutable input leases.

## Out of scope
Transferring huge projection results and whole-scene Unity-thread input copies.

## Automated acceptance criteria
A1. Affected assemblies compile. A2. Safe operations progress; sensitive ones reject with correction; unlock waits for both terminal states while transport stays live. A3. Disconnect cancellation, manual/automatic policy and stale native completion are deterministic; no scene-sized Unity-thread copy.

## Verification contract

## Human acceptance

No `hbp_core` or assembly-definition changes are needed.
