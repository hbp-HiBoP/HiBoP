# T12 - Online filter job

## Objective
Run online filtering only on Desktop and transfer one canonical typed result.

## Shared context and dependencies
T11 ordinary handlers; long-job and replication contracts.

## Scope and preserved contracts
Command/generation, global busy scope, 200 ms delayed visual, Desktop compute, roster bitset, chunked transfer, Quest atomic apply, offline capability gate, cancellation and stale rejection.

## Out of scope
Quest online recomputation and automatic offline resume after confirmed loss.

## Automated acceptance criteria
A1. Affected assemblies compile. A2. Desktop alone computes online; both unlock only after correct Quest apply, with typed checkpoint result. A3. Loss cancels, old/partial results cannot publish, network remains internally live, and delayed visual respects 200 ms.

## Verification contract
Static gate then focused job/SceneFocused MCP tests; poll completed job, console and exact counts/times. Include deterministic A-cancel/B-complete/A-late race.

## Human acceptance
Review busy scope, delayed loading and failure feedback.

## Unresolved decisions
UNRESOLVED: exact UI/prefab scope, future tests/counts, offline capability fixture.

## Completion report
Report compute ownership, apply ACK and failure boundaries.
