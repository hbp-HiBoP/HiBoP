# T16 - Single-scene checkpoint reconciliation UX

## Objective
Implement no-merge reconciliation for one common incarnation.

## Shared context and dependencies
T06 authority plus completed handler/checkpoint families; replication and lifecycle contracts.

## Scope and preserved contracts
Checkpoint identity, silent equal reconnect, global Desktop/Quest choice for the one scene, 200 ms delayed progress, bounded cancelable staging, interaction lock, prevalidation, commit/failure, orphan indicator and retry.

## Out of scope
Three-way merge, persistent offline history and T17 multi-scene UI.

## Automated acceptance criteria
A1. Affected assemblies compile. A2. Either choice converges without source resources; equal identity is silent; offline Desktop close leaves Quest local. A3. Interrupted staging applies nothing, commit failure is explicit/out-of-sync, retry works and no state survives process death by contract.

## Verification contract
Static gate then focused SceneFocused MCP tests with fake loss/staging; poll job, inspect console and exact results. Human UX review is separate.

## Human acceptance
Review delayed progress, choice and orphan/out-of-sync UX.

## Unresolved decisions
UNRESOLVED: identify the prerequisite handler/checkpoint families. UI/prefab scope and test names/counts remain open.

## Completion report
Report choice/commit failure boundaries and manual UX.
