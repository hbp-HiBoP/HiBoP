# T02 - Resource manifest and initial-transfer performance repair

## Objective
Give prepared resources stable bounded identities without adding data passes to click-to-visible transfer.

## Shared context and dependencies
T01 contracts, T00 baseline, transport performance and scene lifecycle.

## Scope and preserved contracts
Initial/full delivery remains separate from live mutations. Keep the existing SHA checks over serialized resources, buffer packs, and delivery receipts. Do not add a second semantic pass over mesh geometry or MEG samples: it rereads large buffers without improving detection of transport corruption. After capture, projection changes to live UVs must not trigger a rescan or rejection. The captured buffer digest still covers the UV bytes actually sent. Preserve first-byte/first-visible telemetry and Quest presentation.

## Out of scope
Live-operation scheduling and new heavy incremental resources.

## Automated acceptance criteria
A1. Transfer/Quest runtime and focused transfer tests compile. A2. Production receive rejects serialized resource/buffer or delivery-receipt digest mismatches; tests cover this existing integrity path and no dedicated mesh/MEG fingerprint pass remains. A3. Paired regression measurements meet the T00 transfer budget; duplicate surface/MEG work and per-frame `columns.ToArray()` are removed where still present.

## Verification contract
Static gate precedes task-focused `Sync.SceneFocused` EditMode MCP tests. Poll completed job, inspect console, retain fresh timing and transfer evidence; skipped/zero tests fail. The physical or click-to-visible measurement is a separate manual gate and cannot be passed by unit tests.

## Human acceptance

Compare paired runs against the 30-second request-to-publication target and 20% regression bound. A physical Quest measurement is currently unavailable because no headset is connected; report it as unmeasured, not passed.

## Resolved implementation decisions
- Resource references remain bound to the prepared manifest/descriptor and roster for the delivery epoch. Captured surface digests include the serialized UV bytes for transport integrity; later live projection changes do not trigger recalculation or rejection.
- Keep byte-level integrity checks already performed during serialization, resource extraction, buffer-pack verification, and delivery receipt validation.
- Remove the extra mesh geometry and MEG content fingerprint generation/comparison passes. Their only additional protection was detecting capture/restoration logic defects or in-memory changes that differ from the serialized bytes; fixing such defects through another full data pass is not worth its transfer-time cost for this task.
- Existing corruption tests for archive resources, packed buffers, and transport receipts qualify for A2. No physical timing evidence is available in the current environment.
