# T03 - Pure scheduler, backpressure and job freshness

## Objective
Prove bounded lane scheduling, independent reliable streams, coalescing and job freshness before networking.

## Shared context and dependencies
T01 types; wire, transport and verification contracts.

## Scope and preserved contracts
Keep structural records in scene-operation order, assign origin sequence at wire commitment, retain written reliable previews unchanged, route oversized bodies via descriptor plus independent bulk stream, and bound every queue/cache.

## Out of scope
Socket loops, Unity scene binding and broad operation families.

## Automated acceptance criteria
A1. Sync runtime/tests compile. A2. Deterministic fake-time tests cover lanes, per-stream sequences, coalescing/barriers, bulk fairness, conflict indexes, checkpoint identity and stale jobs. A3. Test overflow, ACK loss, retry, preview pressure, large atomic routing and cancel/interactive progress during bulk resume within measured bounds.

## Verification contract
Static gate, then focused `Sync.Fast` MCP EditMode run in `HBP.Sync.Tests`; poll completion, inspect console, require named fresh tests and execution time.

## Human acceptance
Review measured inline threshold, fairness burst and queue limits.
