# Jalons de démonstration

Un jalon répond à une question produit et rassemble plusieurs unités de review.
Il ne demande pas à un agent de faire un énorme diff en une seule livraison.
Utiliser les IDs QUEST pour commander une unité d'implémentation.

| Jalon | But | Tâches |
| --- | --- | --- |
| [J0 — Baseline et fixture](J0.md) | Identifier la base de travail et ouvrir une fixture MNI complète reproductible. | QUEST-001 |
| [J1 — Un projet, deux Players](J1.md) | Conserver le Desktop Windows et afficher passthrough/contrôleurs Quest depuis le projet unique. | QUEST-002, QUEST-003, QUEST-004 |
| [J2 — Anatomie transférée et manipulable](J2.md) | Envoyer la colonne ouverte vers le casque puis la manipuler hors ligne. | QUEST-005, QUEST-006, QUEST-007, QUEST-008, QUEST-009, QUEST-010, QUEST-011, QUEST-012 |
| [J3 — Électrodes associées](J3.md) | Recevoir et afficher des contacts synthétiques dans le même repère. | QUEST-013, QUEST-014 |
| [J4 — Densité calculée localement](J4.md) | Charger le moteur Android et exécuter la même tranche densité que Desktop. | QUEST-015, QUEST-016, QUEST-017, QUEST-018, QUEST-019 |
| [J5 — iEEG d'un instant et qualification Windows](J5.md) | Transférer un instant préparé, le projeter localement et qualifier l'ensemble Windows–Quest. | QUEST-020, QUEST-021, QUEST-022, QUEST-023, QUEST-024 |
| [J6 — Qualification Mac Apple Silicon](J6.md) | Refaire le parcours complet depuis un Mac physique. | QUEST-025, QUEST-026 |
| [J7 — Décision Linux puis qualification éventuelle](J7.md) | Décider du test Linux, puis le réaliser uniquement si retenu. | QUEST-027, QUEST-028, QUEST-029 |

Pour qualifier un jalon, relire les rapports des tâches, exécuter la démonstration
finale pertinente et enregistrer les retours manuels. Ne pas rejouer chaque test
sans changement ou doute justifiant cette répétition.
